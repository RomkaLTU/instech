## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

The page uses the system font stack (`Arial, Helvetica, sans-serif`), so no web fonts are downloaded.

## Pages

- `/` — "Hello, world!" page, with a link to the calculator.
- `/calculator` — illustrative car insurance premium calculator. Enter a car value (€1–€1,000,000, whole euros) and a driver's age (18–100, whole years) to see an estimated monthly premium: 3% of the car value per year, ×1.5 for drivers under 25, divided by 12 and rounded half up to the cent. Prices are examples, not insurance quotes. The rules live in `lib/premium.ts`.
